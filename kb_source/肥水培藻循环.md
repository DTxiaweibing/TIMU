# 肥水=培藻 循环流程图

## 图例标识
- 紫色圆点：碳源
- 红色线条：有氧环境
- 灰色线条：缺氧环境

## 核心流程逻辑
1. **两大肥源输入**
    - 有机肥（人工施肥）：经分解型菌分解供给藻类；未被藻类完全吸收部分进入水体循环
    - 无机肥（人工施肥，含水源、矿物质、无机盐）：直接供给藻类，未完全吸收进入水体
2. **藻类核心供氧分支**
    藻类光合作用供氧，供给三类物质：
    - 微生物、水体动物
    - 有机氮、残饵、粪便等污物
    污物经芽孢、粪肠、光合类微生物分解，进入**氨化**流程生成氨态氮
3. **氮转化链条（有氧/缺氧区分）**
    1. 氨态氮去路：
        - 直接被藻类同化吸收
        - 有氧条件下经亚硝酸菌转化为亚硝酸盐；氧化细菌可氧化改底，将亚硝酸盐转回氨态氮
    2. 亚硝酸盐去路：
        - 有氧：亚硝螺旋菌转化为硝酸盐
        - 缺氧：反硝化细菌将亚硝酸盐转化为硝酸盐
    3. 硝酸盐：一部分被藻类同化吸收；另一部分藻类同化剩余碳源回流循环
4. **闭环回流**
    有机肥分解残余、氮循环未被吸收产物、藻类代谢碳源全部回流至藻类形成完整肥水培藻循环
